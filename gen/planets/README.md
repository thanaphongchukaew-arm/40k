# ข้อมูลดาวของแผนที่กาแล็กซี

**แหล่งข้อมูลจริง (source of truth) คือ `js/planets-data.js`** ซึ่งเก็บดาวทั้ง 968 ดวงพร้อมเนื้อหาภาษาไทยครบแล้ว
แก้ข้อมูลดาวที่ไฟล์นี้ได้โดยตรง แล้วรัน

```
python3 gen/planets/check.py
```

สคริปต์นี้จะตรวจ id ซ้ำ ฟิลด์ที่ขาด สถานะ รูปที่หายไป พิกัด และลำดับ rank

## ฟิลด์ของแต่ละดาว

| ฟิลด์ | ความหมาย |
|---|---|
| `id`, `name`, `th` | รหัส (ใช้ในลิงก์ `galaxy-map.html#p-<id>`) ชื่ออังกฤษ ชื่ออ่านไทย |
| `st` | สถานะ: `stable` `war` `retaken` `destroyed` `chaos` `xenos` `unknown` (ไม่มีแหล่งอ้างอิง ให้ใช้ `unknown`) |
| `seg`, `sector`, `system`, `x`, `y` | ที่ตั้ง · `x`,`y` คือพิกัดบนแผนที่ขนาด 1400×1120 (ไม่มีพิกัด = อยู่แค่ในรายชื่อ) |
| `type`, `pop`, `aff`, `gov`, `tithe`, `climate` | ข้อมูลจาก infobox ของ wiki |
| `sum`, `life`, `ev`, `now`, `fact` | เนื้อหาไทย: สรุป ชีวิตผู้คน เหตุการณ์ ปัจจุบัน เกร็ด |
| `img`, `cap` | รูปใน `images/` และคำบรรยาย (ต้องเป็นรูปดาว/ฉากบนดาวจริง ห้ามใช้โลโก้ ตราทัพ หรือรูปตัวละคร) |
| `score`, `rank` | ความสำคัญ ใช้เรียงลำดับ (rank 1 = สำคัญสุด) |
| `src`, `lore` | ลิงก์บทความต้นฉบับ · มีเนื้อเรื่องหรือไม่ |

เมื่อเพิ่มรูปใหม่ ให้ใส่ใน `pages/credits.html` และ `sw.js` (IMAGES) ด้วย แล้วเพิ่มเลข `?v=` ของ `planets-data.js` ใน `pages/galaxy-map.html` และ `sw.js`

## โฟลเดอร์ย่อย (เก็บไว้อ้างอิง)

- `th/b01.py`–`b13.py` — คำแปลไทยต้นฉบับที่ใช้สร้างข้อมูลรอบแรก (`TH` = เนื้อหา, `DROP` = รายการที่ไม่ใช่ดาว)
- `pipeline/` — สคริปต์ที่ใช้ดึงข้อมูลจาก Warhammer 40k Wiki (Fandom API): harvest → verify → digest → assemble → build
  สคริปต์เหล่านี้อ้างพาธชั่วคราวของเครื่องที่ใช้สร้าง และไฟล์ข้อมูลดิบขนาดใหญ่ (digest.json ~3MB) ไม่ได้เก็บไว้
  ถ้าจะรันใหม่ต้องแก้ตัวแปร `S`/`SITE` และดึงข้อมูลจาก wiki ใหม่ · `build_planets.py` เคยอ่านรายการดาวเดิมจาก `galaxy-map.html` ซึ่งตอนนี้ย้ายมาอยู่ใน `planets-data.js` แล้ว
- รูป 56 รูปที่ถูกคัดออก (2026-09-25) เพราะเป็นโลโก้/ตราทัพ/รูปตัวละคร ไม่ใช่รูปดาว — อย่านำกลับมาใช้
